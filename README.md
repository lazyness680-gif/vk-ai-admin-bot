**Название проекта:** ИИ-администратор для салона оптики «ФОКУС» — виртуальный консультант с характером и именем **Ирина**.

Бот для сообщества ВКонтакте: консультирует по оправам, линзам и ремонту, считает стоимость и **записывает клиента на услугу только в реально свободное время**. Все обращения складывает в Excel для администратора и уведомляет его в личку.

---

## 🎯 Решаемая задача

Салон терял обращения в сообщениях ВКонтакте: администратор не успевал отвечать, клиенты уходили к конкурентам, а записи на примерку и ремонт оформлялись вручную и иногда путались. Нужен был ИИ-администратор, который:

- отвечает **24/7**, включая вечера, выходные и обеды;
- консультирует по оправам, линзам и ремонту на базе знаний салона;
- **сам доводит клиента до записи** — без звонков и ожидания «пока админ освободится»;
- не выдумывает время: записывает только в слоты, свободные по реальному расписанию мастеров;
- передаёт администратору готовую заявку: имя, телефон, услуга, дата, время, мастер.

Всё это закрывается одним ботом с персонажем, скриптами и инструментами.

## 👥 Целевые пользователи

| Пользователь | Что получает |
|---|---|
| **Клиент салона** (люди 25–60 лет, выбирают очки, чинят оправу, проверяют зрение) | Мгновательный ответ в привычном мессенджере, консультацию, честные цены и запись за пару сообщений |
| **Администратор** | Не тонет в однотипных вопросах: заявки уже оформлены в Excel, уведомления — в личке; разбирает только сложные случаи |
| **Владелец салона** | Обращения не теряются, запись идёт даже ночью, вся статистика заявок — в таблице |

## 📖 Пользовательские сценарии

1. **Подбор очков.** Клиент: «Хочу лёгкие оправы до 5000 ₽» → Ирина показывает позиции каталога с ценами и наличием, предлагает записаться на примерку.
2. **Ремонт.** «Сломалась дужка» → бот уточняет детали словами (фото модель не видит — и честно об этом говорит), предлагает осмотр мастера, показывает свободное время.
3. **Проверка зрения.** Клиент выбирает удобный слот оптометриста → запись создаётся с первого подтверждения.
4. **Консультация со счётом.** Модель собирает заказ (оправа + линзы + работа) и считает итог через инструмент расчёта — не «на глаз».
5. **Перенос записи.** Клиент хочет другую дату → бот сначала проверяет новые слоты, старую запись держит до подтверждения переноса.
6. **Сложный случай.** Жалоба, нестандартный вопрос или «позовите человека» → заявка передаётся администратору с уведомлением в VK.
7. **Согласие на ПД.** Перед сохранением телефона бот отдельно спрашивает согласие на обработку персональных данных.

## ⚙️ Как проходит запись (под капотом)

1. Клиент пишет в сообщество → Long Poll отдаёт событие `message_new`.
2. Бот проверяет: не дубль, не флуд, не сообщение сообщества.
3. Собирает историю диалога (последние 16 сообщений, TTL 12 часов).
4. Отправляет запрос в ProxyAPI с системным промптом, базой знаний и инструментами.
5. Модель вызывает `get_free_slots` → бот считает сетку по графикам мастеров, квалификации, обедам и существующим записям.
6. Клиент подтверждает → `book_slot` **атомарно** занимает слот и создаёт заявку.
7. Заявка уходит строкой в `data/leads.xlsx` (25 колонок, 11 статусов).
8. Администратору приходит уведомление в VK (если задан `ADMIN_VK_ID`).

Свободное время = рабочие часы мастера − обед − существующие записи − удержания. Времени, которого нет в ответе функции, бот назвать не может — так защищаемся от «галлюцинированных» записей.

## 🤖 Возможности

- **Консультации по базе знаний** — цены, FAQ, ассортимент, сравнение линз из Excel-файла; таблицу можно менять на ходу (промпт пересобирается раз в сутки).
- **6 инструментов модели**: свободные слоты, запись, сохранение заявки, каталог, расчёт заказа, передача человеку.
- **Реальное расписание** — слоты строятся по графикам и квалификациям мастеров; на ремонт предложит только мастера с навыком `repair`.
- **Каталог оправ** с фото и ценами из `catalog.xlsx` (позиции без наличия не показываются).
- **Заявки в Excel** для администратора; если файл открыт в Excel — строка не теряется, уходит в `outbox` и доезжает через минуту.
- **Уведомления админу** в личные сообщения VK: новая запись, вопрос клиента, передача человеку.
- **Безопасность**: секреты в `.env`, лимиты запросов, защита от prompt injection (16 паттернов), маскирование ключей в логах, валидация имени и телефона, согласие на ПД.
- **Устойчивость**: защита от двойного запуска, автозапуск на Windows, ротация логов, восстановление после сетевых сбоев.

## 🚀 Быстрый старт

```powershell
git clone https://github.com/lazyness680-gif/vk-ai-admin-bot.git
cd vk-ai-admin-bot

# 1. зависимости
python -m pip install -r requirements.txt

# 2. рабочие файлы: data/salon.json, masters.json, catalog.xlsx, leads.xlsx
python run.py --init

# 3. ключи: скопируйте .env.example в .env и заполните
#    VK_TOKEN, VK_GROUP_ID, PROXYAPI_KEY

# 4. диагностика без запуска бота
python run.py --check

# 5. запуск
python run.py
```

**Ключ ВКонтакте** (Управление → Работа с API): ключ доступа с правами «Управление сообществом» и «Сообщения сообщества»; Long Poll включён, версия API 5.199+, событие `message_new`.
**Ключ ProxyAPI**: создать в кабинете (начинается с `sk-`), пополнить баланс.

Необязательные настройки: `ADMIN_VK_ID` (уведомления), `MAX_DAILY_LLM_CALLS` (2000), `RATE_LIMIT_PER_MINUTE` / `RATE_LIMIT_PER_HOUR`, `LOG_LEVEL`.

## 🧩 Настройка под свой бизнес

- **`data/salon.json`** — адрес, телефон, часы, оплата, доставка. Пока стоит `ЗАПОЛНИТЕ`, бот не выдумывает, а говорит «уточню у администратора».
- **`data/masters.json`** — кто, когда и что делает: навыки (`repair` / `optometry` / `sales`), дни, часы, обед, шаг слота. Отпуск — просто уберите день.
- **`data/catalog.xlsx`** — оправы: `Модель | Материал | Цвет | Цена | Наличие | Фото`. Перечитывается автоматически.
- **База знаний** — любой xlsx: каждый лист превращается в markdown-блок промпта. Меняете таблицу — бот отвечает по-новому.
- **Системный промпт** — характер, скрипты, правила безопасности; технические разделы в модель не попадают.

## 🔒 Безопасность

Подробный отчёт — в [SECURITY.md](SECURITY.md). Ключевое:

- секреты только в `.env` (в git не попадает), маскирование в логах и ответах;
- текст клиента помечается как данные + эвристика на 16 паттернов против prompt injection;
- запись возможна только через `get_free_slots` → `book_slot` с атомарной перепроверкой слота;
- лимиты: 10 сообщ./мин и 80 сообщ./час на пользователя, 2000 запросов к модели в день;
- SQL только через параметры, формулы Excel нейтрализуются, согласие на обработку ПД — обязательный вопрос.

## 🖥 Автозапуск на Windows

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1   # ярлык в автозагрузку
scripts\stop_bot.bat                                                    # остановить
```

Защита от двойного запуска: второй экземпляр пишет строку в лог и выходит — гонки за слоты не будет.

## ⚠️ Ограничения

- GPT-4o mini не распознаёт фото — бот просит описать проблему словами.
- Медицинские вопросы не консультирует — только запись к оптометристу.
- Оплата в чате не принимается.
- Один экземпляр бота на одно сообщество.
